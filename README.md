# Company Dashboard

Демонстрационная веб-система для работы с данными трёх производственных участков: заготовки, потребности сварки и документации.

Приложение объединяет данные в одной системе и предоставляет руководителю сводную панель с показателями, графиками и детализацией записей.

## Возможности

- Импорт данных из трёх Excel-файлов.
- Просмотр и редактирование записей через веб-интерфейс.
- Панель руководителя с основными показателями, сводными таблицами и графиками.
- Фильтрация данных по выбранному периоду.
- Сопоставление заготовок и потребности сварки по идентификатору партии `batch_id`.
- Проверка качества данных: поиск дубликатов, отрицательных значений, подозрительных и отсутствующих значений.
- Отображение предупреждений для связанных расчётов, требующих проверки.
- Экспорт отчётов в Excel и CSV.
- Сохранение изменений в базе данных.

## Установка и запуск на Windows

### 1. Скачайте проект

Клонируйте репозиторий:

```powershell
git clone <https://github.com/kktzxd/company_dashboard>
```

Перейдите в папку проекта:

```powershell
cd company_dashboard
```

### 2. Создайте виртуальное окружение

```powershell
py -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Установите зависимости

```powershell
python -m pip install -r requirements.txt
```

### 4. Подготовьте базу данных

```powershell
python manage.py migrate
```

### 5. Запустите сервер

```powershell
python manage.py runserver
```

Откройте приложение в браузере:

http://127.0.0.1:8000/

Для остановки сервера нажмите `Ctrl+C` в терминале.

## Начало работы

1. Откройте экран загрузки данных.
2. Загрузите Excel-файлы «Заготовка», «Потребность сварки» и «Документация».
3. Перейдите на панель руководителя и выберите интересующий период.
4. Просмотрите показатели, графики, предупреждения и детализацию.
5. При необходимости исправьте записи через интерфейс системы.
6. Скачайте отчёт в Excel или CSV.

После импорта данные хранятся в базе приложения. Для дальнейшей работы исходные Excel-файлы не требуются.

## Логика расчётов

- Заготовки и потребность сварки сопоставляются по `batch_id`.
- Разница рассчитывается как фактическое количество заготовок минус потребность сварки.
- Отсутствующий факт не считается нулём.
- Подозрительные и некорректные значения отмечаются для проверки.
- Данные документации рассчитываются независимо, поскольку явная связь с другими участками не задана.

## Примечания

Проект предназначен для демонстрации и использует учебные данные. Для локального запуска требуется установить Python-зависимости и выполнить миграции базы данных.

Если база данных не включена в репозиторий, после первого запуска она будет создана без импортированных записей. Для заполнения необходимо загрузить исходные файлы через интерфейс приложения.
